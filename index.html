Formatação, Apresentação e Lógica em WEB

A programaçãode páginas web tem como objetivo a criação de conteúdos estruturados que permitam o acesso e vizualização para users na internet.

Frequentemente, três tecnologias são unidas para isso: HTML, CSS e JavaScript.

  1. HTML: Formatação e estrutura
  2. CSS: Apresentação e estilo
  3. JavaScript: Lógica e interatividade

Formatação: HTML

O HTML (HyperText Markup Language ou Linguagem de Marcação de Hipertexto) é a linguagem de marcação padrão usada para criar e estruturar páginas e aplicativos na web

O que o HTML faz?

  • Define o esqueleto: Organiza os elementos da página
  • Não é linguagem de programação: Não possui lógica de programação
  • Usa tags: Utiliza tags, que são marcações da forma de um conteúdo

Apresentação: CSS

O CSS (Cascading Style Sheets ou Folhas de Estilo em Cascata) é uma linguagem de estilo usada para descrever a apresentação de um documento escrito em HTML ou XML.

O que o CSS faz?

  • Define o estilo: Controla a aparência visual da página
  • Não é linguagem de programação: Não possui lógica de programação
  • Usa seletores e propriedades: Aplica estilos aos elementos HTML

Lógica: JavaScript

O JavaScript é uma linguagem de programação que permite adicionar interatividade e funcionalidades dinâmicas a páginas web.

O que o JavaScript faz?

  • Adiciona interatividade: Permite que os usuários interajam com a página
  • Manipula o DOM: Pode alterar o conteúdo e a estrutura da página
  • Realiza operações lógicas: Pode executar códigos condicionais e de loop

Conclusão

Em resumo, o HTML fornece a estrutura, o CSS define a aparência e o JavaScript adiciona interatividade às páginas web. Juntas, essas tecnologias permitem criar experiências web ricas e envolventes para os usuários.
